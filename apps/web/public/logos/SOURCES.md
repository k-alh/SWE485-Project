# Company logos

Files in this folder are the official marks of the organisations used in the
mock listing data. They are trademarks of their respective owners and appear here
only to identify each organisation on its card and detail page in this coursework
project.

Each file was downloaded once at build time and is served from this folder, so the
app makes no requests to third-party hosts at runtime.
